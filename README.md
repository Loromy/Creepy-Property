# Creepy Property - Eigenständige Webseite

Diese Webseite präsentiert das **Creepy Property** JavaFX-Adventure-Game.

## 📁 Struktur

```
creepy-property/
├── index.html      # Hauptseite
├── style.css       # Standalone CSS mit grünem Horror-Theme
├── main.js         # JavaScript für Theme-Toggle und Navigation
└── README.md       # Diese Datei
```

## 🌿 Features

- **Komplett eigenständig** - Keine Links zurück zum Haupt-Portfolio
- **Grünes Horror-Theme** - Passend zum Spielthema
- **Responsive** - Mobile-freundlich
- **Dark/Light Mode** - Theme-Toggle Funktionalität
- **Animationen** - Nebel-Effekte, schwebende Partikel
- **GitHub Integration** - Direkte Links zum Repository

## 🔗 Navigation

Die Webseite ist komplett eigenständig:
- **Features** - Sprunglink zu Features-Sektion
- **Download** - Sprunglink zu Download-Sektion
- **GitHub** - Externer Link zum Repository

## 🎯 Einbindung

Diese Webseite wird von außen über das Portfolio verlinkt:
- Von `../portfolio.html` erreichbar
- Von `../projekte.html` erreichbar
- **Kein Rückweg vorhanden** - komplett eigenständige Präsenz

## 🎨 Anpassungen

Das grüne Farbschema kann in `style.css` angepasst werden:
```css
--creepy-green: #00ff41;
--creepy-dark-green: #00cc33;
--creepy-bright-green: #33ff66;
```
