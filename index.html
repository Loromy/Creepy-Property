📖 Über das Projekt

Creepy Property ist ein JavaFX-basiertes Adventure-Game. Der Spieler wacht in einem alten, dunklen Herrenhaus auf und muss einen Weg hinaus finden. Dabei durchläuft er mehrere Level, sammelt Schlüssel, meidet Geister und löst Aufgaben, um zu entkommen.

Die Entwicklung umfasst fortgeschrittene JavaFX-Features wie KI-Systeme für Geister-Gegner, Kollisionserkennung (CollisionChecker), Map-System mit LevelData, Sound-Integration und ein komplexes Entity-System für Player und Enemies.

Das Projekt verwendet Java 23 mit JavaFX 17 und Maven als Build-Tool. Der vollständige Source Code ist auf GitHub verfügbar unter der Creative Commons BY-NC-ND 4.0 Lizenz - du darfst es nutzen, teilen und zeigen, solange du den Urheber (Loromy) nennst und es nicht kommerziell nutzt.
